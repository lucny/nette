# Kurz Nette Framework pro začátečníky

Praktický český kurz vede od základů PHP k funkční databázové administraci produktů v Nette Frameworku.

Začněte [mapou kurzu](course/COURSE-MAP.md) a připravte prostředí podle [README kurzu](course/README.md). Výukové texty jsou ve složce [lekce](lekce/).

Kurz používá PHP 8.3+, MySQL 8.4, Composer a Nette 3.3.x. Zdrojový kód aplikace je v kořeni repozitáře; skutečné lokální přihlašovací údaje patří pouze do ignorovaného `config/local.neon`.
