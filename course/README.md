# Studijní rozcestník kurzu

Hlavním portálem kurzu je [README v kořeni repozitáře](../README.md). Najdete v něm bezpečné zprovoznění referenční aplikace, mapu všech kapitol, příkazy pro ověření i odkazy na aktuální oficiální dokumentaci.

Tato složka doplňuje tři materiály, které při studiu používejte takto:

| Materiál | Kdy jej otevřít | Co z něj získáte |
|---|---|---|
| [Mapa kurzu](COURSE-MAP.md) | když hledáte konkrétní kapitolu nebo soubor | pořadí lekcí a výsledek každé z nich |
| [Plán kurzu](COURSE-PLAN.md) | když si chcete udělat přehled o návaznostech | témata PHP, Nette a odhad času |
| [Závěrečný report](FINAL-REPORT.md) | po dokončení všech kapitol | přehled hotových částí aplikace |

Kurz začíná v [lekci 0](../lekce/0-lekce.md). Postupujte číselně: každá kapitola obsahuje měřitelný cíl, vysvětlení PHP i Nette, přesně označené citace kódu, experiment, samostatný úkol, minikvíz a kontrolní body.

> **⚠️ Bezpečnostní hranice**
>
> Pracujte jen s lokální databází, demonstračními CSV a výukovým účtem. Read-only API je v tomto projektu veřejné pouze kvůli výuce; skutečná aplikace by před zveřejněním dat potřebovala posoudit oprávnění, rozsah odpovědi a limity požadavků.
